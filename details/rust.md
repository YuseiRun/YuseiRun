# Rust ![Rust](https://img.shields.io/badge/Rust-000000?logo=rust&logoColor=white)

I started to make a project in Rust and enjoyed my time working on it (for the most part). The rust community is very enthusiastic about their language, so much so they have Rustlings, a tool used for teaching how Rust works. Coming from Java this felt great, very opinionated and ridged. If Java was a weighted blanket, Rust felt like a straight jacket.. which is where I started running into motivation issues. It felt like every time I press :w, I would see so many errors. Obviously, this was as skill issue on my part, but it did take away from learning the hobby.

## Why did I try Rust?

For years I heard many people across the internet talk about how amazing Rust was as a programming language and how the borrow checker was revolutionary. Being a US based developer and the decree that was sent out (loosely quoting) "all government software will need to be written in Rust", make me feel like I needed to learn it, if everything goes under then at least I could work for the government.. right? I was talking to my friends about how much I enjoyed rust and how cool the rust-analyzer project was and how much a loved that when you saved it helped you see where you were not following rust's conventions and where it would break.

## Would I go back to using Rust?

Yes of course. Even though Rust doesn't feel as artisanal as Odin, I still enjoyed writing in it. Right now I just have other languages I want to try, books I want to read, activities I want to partake in that I will fondly put this on the self for another day.
